# Preference Game Lab

An interactive page for MIT 6.7980, session 5: RLHF read as a game. Bradley-Terry reward modelling versus Nash learning from preferences by self-play, with editable preference matrices, an AI-judge blend, and five no-regret learners.

Live page: https://htansetiawan.github.io/preference-game-lab/

Everything runs in the browser; the responses and preference numbers are illustrative and no language model is called.
